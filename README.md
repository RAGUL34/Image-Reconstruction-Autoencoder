# CelebA Image Autoencoder

A simple Deep Learning project that uses a **CNN Autoencoder** to reconstruct face images from the **CelebA dataset**.

## 🧠 What This Project Does

* Loads CelebA face images
* Converts images to grayscale
* Resizes images to **28 × 28**
* Uses a CNN Encoder to extract features
* Uses a Decoder to reconstruct the images
* Compares original and reconstructed images

## 🛠️ Technologies

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib
* Pillow

## 📌 Model Flow

```text
Input Image
     ↓
CNN Encoder
     ↓
Compressed Features
     ↓
CNN Decoder
     ↓
Reconstructed Image
```

This project helped me understand **CNNs, Autoencoders, Image Reconstruction, and TensorFlow/Keras model training**.
